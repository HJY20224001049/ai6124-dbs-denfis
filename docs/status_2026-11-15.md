# Status — 2026-11-15 (pre-freeze checks)

The freeze candidate is still B2; the 2017–2025 test years and the 2026 holdout
remain untouched. This note records what was added on 2026-11-15 and what it
changes. Nothing here authorises a test or holdout run.

## 1. Implementation audit (`docs/implementation_audit.md`)

The instructor suspected an implementation error. Three checks now answer that:

- the target is the price difference `ln(AdjClose_{t+1}/AdjClose_t)`, not the level;
- a single-rule model is a closed-form linear fit: coefficients match
  `(ΦᵀΦ + 0.01·I)⁻¹Φᵀy` to 8e-17 and predictions to 9e-16, and the distance from
  plain OLS on real folds is 1.3–1.4×10⁻⁶ × sd(y);
- the same pipeline beats the zero forecast by 2.45% (DENFIS), 2.10% (XGBoost)
  and 1.48% (LSTM) on a synthetic target with a known signal.

The one-rule prior comes from the covariance initialisation (`100·I`), so the
model is a lightly regularised linear fit, not plain OLS. The method chapter and
the slides now say this.

## 3. Fair validation (no selection on the scored year)

The protocol runner early-stops XGBoost and the LSTM on the validation year and
then scores that same year. Re-scoring both with inner early stopping
(`scripts/fair_validation.py`, `docs/fair_validation.md`):

| model | mean validation skill | median | folds > 0 | pooled skill |
|---|---:|---:|---:|---:|
| B2 (fixed parameters) | **+0.497%** | +0.616% | 8/9 | **+0.480%** |
| XGBoost (fair) | +0.021% | −0.036% | 4/9 | −0.029% |
| LSTM (fair) | −1.237% | −0.621% | 3/9 | −0.887% |

Ordering on mean validation skill: **B2 > XGBoost > LSTM > zero**, which is the
ordering the instructor's definition asks for. Caveats: the fair baseline numbers
are conservative (one-year-shorter inner window; two folds pick a single tree),
and B2 is itself the best of sixteen validation-selected variants, so this is
validation-against-validation, not confirmation.

## 4. Statistics (`docs/statistical_tests.md`)

- Clark–West against the zero forecast (one-sided): DENFIS frozen rejects the
  no-information null at 5% (stat 1.73, p 0.042); XGBoost, LSTM and the online
  variant do not. This is not an MSE-improvement test — the adjustment credits
  the forecast's own variance, so the positive statistic alongside a worse RMSE
  is the over-dispersed-forecast signature.
- Range-based model confidence set (α = 0.10, stationary bootstrap): all five
  models survive; no model is significantly worse than the best.
- Minimum detectable effect table folded into the same report (0.50% for `ma5`,
  0.80% for XGBoost against zero, 1.26% for DENFIS against zero at n = 2258).
