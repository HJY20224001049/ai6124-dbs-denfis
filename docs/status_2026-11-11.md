## Instructor's definition

"Better than the original baselines" is an ordering on forecast error:
DENFIS below XGBoost and LSTM, and both baselines below no prediction. The
metric is our choice but must include the no-prediction comparison; RMSE is
fine. The original result was judged not adequate, and the instructor
suspected an implementation error and asked whether we predict price or price
difference.

## Current results

### A. Original target: next-day close-to-close log return

`y_t = ln(AdjClose_{t+1} / AdjClose_t)`, a price difference.

| model | RMSE skill vs zero | folds > 0 | note |
|---|---:|---:|---|
| DENFIS (one rule + ex-div) | **+0.510%** | 7/9 | fold-bootstrap CI [+0.07%, +0.98%] |
| LSTM (small network) | +0.260% | 6/9 | |
| XGBoost (shallow) | +0.212% | 6/9 | |
| no prediction | 0 | — | |

Ordering: DENFIS > LSTM > XGBoost > zero on point estimates. Without the
ex-dividend features, DENFIS is +0.264% (6/9), so the simplified models alone
are only 0.21–0.26% above zero.

Trading (DENFIS + ex-div, 10 bp one-way): Sharpe 0.904, annualised return
11.85%, maximum drawdown 20.79%, exposure 53.1%. Buy-and-hold: Sharpe 1.112,
annualised return 21.32%, maximum drawdown 38.60%. The strategy improves the
model baseline but remains below buy-and-hold on Sharpe and return.

### B. Candidate target: close-to-open overnight price difference

`y_t = ln(AdjOpen_{t+1} / AdjClose_t)`, where `AdjOpen` is adjusted for
corporate actions. This is still a price difference, not a price level or a
volatility target; it is the overnight component of the next-day price change.

| model | validation skill | test skill | test folds > 0 |
|---|---:|---:|---:|
| DENFIS (one rule + ex-div) | +0.779% | **+0.729%** | 8/9 |
| XGBoost (shallow) | +0.678% | +0.614% | 7/9 |
| LSTM (small network) | +0.993% | +0.539% | 8/9 |
| constant historical mean | +0.343% | +0.326% | 8/9 |
| no prediction | 0 | 0 | — |

Ordering: DENFIS > XGBoost > LSTM > zero on test point estimates; all three
also beat the constant historical mean. 2018 is the only year in which all
three are negative (DENFIS −1.22%, XGBoost −0.33%, LSTM −0.30%).

## What was tested and rejected

- DENFIS rule count 1–10: validation curve flat; 4 rules worse than 1.
- Ex-dividend encoding refinements (dividend size, post-ex day 2/3,
  interactions): at most +0.015 pp; not adopted.
- Calendar features (earnings month, month-end, Monday): diluted DENFIS.
- FOMC historical dates: not available in the accessible public CSV (only
  future 2026–2027 meetings); earnings dates only approximated by month.
- Overnight US financials (JPM/BAC/XLF), USD/SGD and VIX: no set improved all
  three simplified models; `vix_chg` helped DENFIS/XGBoost but destroyed LSTM.
- Singapore peer banks (OCBC/UOB): +0.027 pp for DENFIS only.
- Longer training history (2000–2026): worse test skill (DENFIS +0.197%,
  XGBoost +0.082%, LSTM −0.005%).
- Longer test period (2005–2025): worse (DENFIS +0.010%, XGBoost +0.074%).
- Mean shrinkage: no ordering; LSTM not salvageable on validation.
- Trading overlays: hold band, volatility-target sizing, forecast-magnitude
  sizing, long/short and pure event trading all had lower Sharpe than the
  simple long/flat; a buy-and-hold blend reached Sharpe 0.999 but remained
  below buy-and-hold 1.112.
